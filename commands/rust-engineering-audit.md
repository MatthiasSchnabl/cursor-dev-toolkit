# Rust Engineering Audit

Read and follow the plugin skill `skills/engineering/rust-engineering/SKILL.md` completely, including `references/rust-engineering-standard.md`.

## Operation

This command is **audit** only.

- Perform a fresh Rust engineering audit.
- Never start a fix from this command.
- Write audits under `docs/engineering-audits/rust/` in the **current repository**.
- Do not modify production source during audit.
